Sample files are for demonstration purposes only and may contain only a subset of actual data. 
Similarly, different versions of the product file may contain different representative records.

Please refer to the product page and linked product specification therein for further details:
https://datashop.cboe.com/option-eod-summary

Note that two sample versions of the product file are included to show differences in reporting of underlying index values, specifically for ^SPX. Neither version will contain underlying ^VIX values as there is no published bid/ask. Please see the product page for more information on how to obtain ^VIX index values.

Versions:

*cgi_or_historical*
Will contain underlying ^SPX values for 1) daily subscribers that hold an active Cboe Global Indices (CGI) license and 2) any customer that makes a historical purchase (T+1) regardless of CGI license status.

*no_cgi_subscription*
Daily subscribers that do *not* hold an active CGI license will see all underlying index values reported as zero
